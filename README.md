# ResumeLint

The engineering-grade resume linter — an open-source ATS analyzer combining deterministic rule-based scoring with AI-powered suggestions, resume parsing, and recruiter-behavior simulation.

## Status
🚧 Early development — not yet usable.

## Architecture Decisions
See [`docs/adr/`](./docs/adr) for the reasoning behind every major technical decision.

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- AI: Groq + OpenRouter (free-tier, provider-agnostic)
